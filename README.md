# Gaivota Consultoria Contábil — versão inicial independente

Site estático, sem dependências, preparado para Cloudflare Pages.

## Publicação
1. Crie um repositório privado no GitHub e envie `index.html`, `style.css` e `script.js` para a raiz.
2. Cloudflare Dashboard > Workers & Pages > Create > Pages > Connect to Git.
3. Selecione o repositório. Framework preset: None; Build command: vazio; Output directory: `/` (raiz do repositório).
4. Publique e verifique o endereço `.pages.dev` atribuído.
